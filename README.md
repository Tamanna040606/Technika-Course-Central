# 🚀 Technika Course Central

### Explore. Learn. Build Your Future.

Technika Course Central is a modern and interactive course exploration platform designed to help students discover technical fields and programming languages in one place.

Built with React and Vite, the platform features a sleek dark-themed interface, interactive course cards, smooth navigation, and a responsive layout to provide an engaging learning experience.

---

## ✨ Key Features

- 🎨 **Modern UI:** Premium dark-themed design with vibrant gradients and visual effects.
- 📚 **Technical Courses:** Explore different technology domains.
- 💻 **Programming Languages:** Discover popular programming languages.
- 🔄 **Interactive Navigation:** Switch between technical fields and programming languages.
- 🃏 **Course Cards:** Explore individual learning categories through interactive cards.
- 📱 **Responsive Design:** Designed to provide a smooth experience across different screen sizes.
- ⚡ **Fast Performance:** Powered by React and Vite.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Tamanna040606/Technika-Course-Central.git
```

**2. Navigate to the project directory**

```bash
cd Technika-Course-Central
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
